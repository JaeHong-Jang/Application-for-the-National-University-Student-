## 2. 유사 레포 지형

### 2-1. 결론
- **복식학급 코티처를 그대로 포크할 오픈소스는 없다.** "multigrade"로 검색되는 것은 2025년 Google Agentic AI Day 해커톤에서 쏟아진 인도 Sahayak 계열뿐이고, 대부분 라이선스가 없거나 학년별 자료 생성에 그친다. **실시간 학생 응답 수집 + 두 학년 직접지도 시간 충돌 관리**를 함께 묶은 레포는 찾지 못했다 [W1 §3, W2 §1 API 조회]. 차별성 근거로 쓴다(단 "최초·유일"이라고 쓰지 않는다).

## 3. AI 설계

### 3-1. 파이프라인

```
[교사 입력] 학년쌍(3·4) · 교과(사회) · 교과서 단원(선택) · 수업 40분 · 협력강사 유무 · 지난 차시 군집(선택)
   │
① Context Builder ─────── 코드: 학년쌍 판정(SAME_BAND/CROSS_BAND/NON_ADJACENT), 교과×학년군 성취기준 필터,
   │                        충북 4유형·3지도방법 추천표
② Planner (Sonnet 5.5) ── 공통 주제, 학년별 성취기준 선택(주어진 목록에서만), 통합/분리 요소
   │  └ R10 코드 검증 실패 → 그 필드만 재요청(1회)
③ Skeleton Builder ────── 코드: 템플릿으로 블록 골격·시간 확정(예: ★7 │ A■13 B□13 │ A□13 B■13 │ ★7)
④ Filler (Sonnet 5.5) ─── 블록별 활동, 간접지도 카드(누구와·단계·끝 신호·막힐 때·산출물·안내 역할), 학년별 ◎○△
⑤ Constraint Checker ──── 코드: R1~R12. error 있으면 위반 JSON을 ④에 되먹여 수리(최대 2회), warn은 UI 표시
⑥ Critic (Opus 5.5, 선택) 루브릭 C1~C6 점수 + 제안 1개. 자동 반영 안 함, 데모 중엔 끄거나 비동기
   │
[교사 검토·수정·승인] ── 수정 diff 저장(M4)
   │ (수업 중)
⑦ QR 수집 ─────────────── 학생: 학년 버튼 + 자유 질문/답. 계정·이름 없음
⑧ PII/안전 필터 ────────── 코드 정규식 + (⑨ 안에서) Haiku 플래그. SAFETY는 군집하지 않고 교사 알림만
⑨ Clusterer (Haiku 5.5) ─ 1회 호출: 군집 라벨(교사용 진단 문장), 포함 기준, 학년, 연결 성취기준(이번 차시 코드 중), 유형, 대표 질문
   │  └ 코드 검사: question_ids ⊂ 실제 ID, linked_code ∈ 이번 차시 코드
[교사 확인] 군집 이름 수정·병합
⑩ Next-lesson (Sonnet 5.5) 학년별 보충 1 + 심화 1, 모두 "간접지도 10분 카드" 형식, 근거 군집 ID + 성취기준 + 성취수준(A/B/C)
   │  └ ⑤ 검사기 재사용(카드 필수 요소 R4, R10)
[교사 승인] → 다음 차시 분리 구간 INDIRECT 블록에 삽입 → 학생용 학습지 인쇄(정답·교사 메모 제거)
```

### 3-2. AI vs 코드 역할표

| 일 | 담당 | 이유 |
|---|---|---|
| 학년쌍 유형 판정, 성취기준 필터 | 코드 | 학년군 규칙이 결정적이다(`[2..]`=1~2, `[4..]`=3~4, `[6..]`=5~6) [W3 §2.1 검증] |
| 수업유형·지도방법 추천 | 코드(규칙표) | 충북 매뉴얼 9쪽·23~28쪽 [W3 §3.1 검증] |
| 공통 주제, 학년별 활동, 간접지도 카드, ◎○△ 기준 | **LLM** | 자연어 생성이 필요하다 |
| 블록 시간 | 코드(골격) | LLM에 "시간을 바꾸지 말라"고 지시하고 검사기로 다시 확인 |
| 성취기준 원문 표시 | 코드(DB 조회) | LLM이 원문을 쓰지 않으므로 원문 왜곡이 원천 차단된다 |
| 타임라인 제약 R1~R12 | 코드 | 범용 챗봇과 가장 선명하게 갈리는 지점 |
| 질문 군집·오개념 진단 | **LLM**(Haiku 1회) | 아동 맞춤법 오류에 강하고 라벨까지 한 번에 나온다. 수십 개 규모라 임베딩은 과하다 [W2 §0-2, W3 §4.6] |
| 보충·심화 카드 | **LLM** | 성취수준 A/B/C 진술을 근거로 학년별 생성 |
| PII 1차 필터 | 코드(정규식) | 결정적·즉시 |
| 위기 신호 | 코드 키워드 + LLM 플래그 → **사람(교사)** | AI가 응답하지 않는다 |
| 최종 승인 | **교사** | 교육부 윤리원칙 "교수자 전문성 존중", 전북 가이드라인 "최종 검토와 판단은 교사" [W3 §5.1] |

| ⑨ Clusterer | Haiku 5.5 | 약 $0.001 |
| 평가 12시나리오(기준선 + 우리 + Opus 심사) | 혼합 | 수 달러 수준 |

지연 수치는 공식적으로 상대 비교만 있다. **리허설에서 p50/p95를 재고**, 체감 지연은 FlowRail 단계 표시와 블록별 점진 표시로 줄인다. 라이브가 정해진 시간(예: 20초)을 넘으면 같은 입력의 fixture로 자동 대체하고 화면 구석에 "녹화 응답" 표시를 남긴다(정직성).

### 3-5. "그냥 ChatGPT 쓰면 되지 않나?"

| 범용 챗봇 | 함께반 |
|---|---|
| 성취기준 코드를 그럴듯하게 지어낼 수 있다 | 코드 DB에서만 고르고 존재·학년군을 코드로 검증(R10) |
| 두 학년 계획을 줄글로 쓰고 시간 충돌을 검사하지 않는다 | 분 단위 2레인 타임라인 객체 + R1~R12 + 자동 수리 |
| 같은 학년군/걸침/격리를 구분하지 않는다 | 학년쌍 판정 → 충북 4유형·3지도방법 추천 |
| 학생 질문을 복사해 붙여야 하고 개인정보가 섞인다 | QR 익명 수집 → PII 필터 → 성취기준과 연결된 군집 |
| 대화가 끝나면 맥락이 사라진다 | 차시 단위 기록이 다음 설계 입력이 된다 |
| 출력이 문서다 | ■□★ 과정안, 학년별 간접지도 카드, 학습지 인쇄 |

**평가 계획(피치용, W3 §6.2)**

| 지표 | 측정 | 기대 [추론] |
|---|---|---|
| M1 코드 환각률 | 출력 코드 중 DB에 없거나 학년군이 틀린 비율(정규식 추출 + DB 대조, 결정적) | 범용 > 0%, 우리 = 0%(구조상) |
| M2 타임라인 위반 | 범용 출력은 Haiku가 블록으로 "고치지 않고" 옮긴 뒤 R1~R11 검사 / 우리는 수리 후 | 범용 다수, 우리 error 0 |
| M3 루브릭 | C1~C6(+k12 P1~P4 번안) Opus 심사 + 교사 1~2명 블라인드, 일치율 보고 | 우리 ≥ 범용, 특히 C3 간접지도 실행 가능성 |
| M4 교사 수정률 | 승인까지 바뀐 필드 비율 | 파일럿 수치로만 표기 |

시나리오 12개 = 학년쌍 3종 × 교과 4종. 표본이 작으므로 "파일럿 측정, 시나리오 12개, 교사 채점자 n명"을 함께 표기한다. 근거 사례: Oak Aila의 LLM-as-judge 자동평가 [검증: arXiv 2502.10410 초록], EEF ChatGPT 수업 준비 시험(준비 시간 약 31% 절감, 품질 차이 없음) [스니펫].

|---|---|---|---|

| D3 | 교과서 단원↔성취기준↔학년 매핑 직접 작성(본문 없이 단원명만) | `data/units.demo.csv` | 데모 시나리오 단원 + 평가 12시나리오 단원 |

**데모 시나리오 1순위**: 충북 매뉴얼 예시와 같은 **3학년 사회 `[4사01-02]` + 4학년 사회 `[4사05-02]`**(같은 학년군, 부분통합). 두 코드 모두 kr-curriculum에 진술문과 성취수준 A/B/C가 있다 [검증: 2026-11-06 직접 조회]. 질문 군집 장면의 대안으로 3·4학년 수학 `[4수01-03]`(받아올림 덧셈)을 시드로 둔다.

**데이터 주의사항 [검증]**
- kr-curriculum 초등 성취수준은 **A~E가 아니라 대부분 A/B/C 3단계**다(611건 중 594건이 A·B·C, 6건은 수준 없음). 중·고가 A~E다.
- kr-curriculum 초등 폴더에는 **통합교과(바·슬·즐) 파일이 없다.** 1·2학년 통합교과 데모는 피한다(learning-map 원문은 '건' 9건 등 잡음이 있고, `[2건..]`은 2026 개정분이라 적용 학년도 미확인).
- 진술문에도 추출 흔적이 있다. 예: `4사01-02` "…방안을 탐 색한다."(띄어쓰기 깨짐). 그래서 D2 대조가 필요하다.
- 사회·과학은 영역 번호가 단원 단위라 학년군 사이 대응이 안 된다(`4사01`≠`6사01`). 학년군 걸침 시나리오에서는 수동 매핑이 필요하다.
- 교과서 본문·지도서·해설서는 탑재하지 않는다. 성취기준(고시)은 저작권법 제7조 적용 가능성이 높지만 법률 확인은 필요하다 [W3 §2.4 추론].
