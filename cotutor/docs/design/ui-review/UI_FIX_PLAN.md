# UI_FIX_PLAN — 5개 리뷰(R0~R5) 통합 백로그

작성 2026-11-06 · 입력: `R0_reference_benchmark.md`, `R1_hierarchy_typography.md`, `R2_color_contrast_a11y.md`, `R3_layout_spacing_responsive.md`, `R4_component_consistency.md`, `R5_judge_demo.md`, `../DESIGN_CONCEPT.md`

R1~R5의 발견 133건(R1 26 · R2 27 · R3 25 · R4 27 · R5 28)을 겹치는 것끼리 합쳐 **U-01~U-80**으로 정리했다. R0은 근거 자료라 따로 ID를 만들지 않고 해당 항목의 근거로만 적었다.
심각도: **P0** 데모 핵심 메시지를 잘못 전함 · **P1** 눈에 띄게 깨짐 · **P2** 정리. 공수: **S** 30분 미만 · **M** 1~2시간 · **L** 반나절 이상.
"상태"는 구현 뒤에 채웠다(맨 아래 §결과 요약).

## ChatGPT 비교(U-71)에 대한 메모

R5-12는 "같은 과제로 실제 생성한 ChatGPT 과정안을 검사기에 넣는" 장면을 제안했다. 이 저장소에는 실제 ChatGPT 출력이 없다. 지어내면 심사에서 신뢰를 잃으므로 만들지 않았다.
**필요한 것(사용자):** ChatGPT에 같은 과제(3·4학년 사회 40분 복식, 단원 [4사01-02]·[4사05-02])를 준 프롬프트·생성 날짜·전체 출력 캡처. 받으면 블록으로 옮겨 `checkLesson`에 넣고, 나온 결과(위반이 없으면 "간접지도 카드·교사 동선이 아예 없음")만 보인다.
