## 5. 바로 적용할 "1시간 묶음"(S 공수만, 효과 큰 순)

1. **R1-04**: `.font-hand{font-weight:400;font-synthesis:none}` 한 줄. 시그니처 "20분"과 "선생님께"가 바로 깨끗해진다.
2. **R1-03**: `Section` h2를 `text-xl`(20px)로 올리고 `text-[16px]` 2곳을 지운다. 섹션 경계가 생기고 역전이 사라진다.
3. **R1-01 일부**: `Section` 설명 `text-xs`→`text-sm`. 모든 섹션에 한 번에 적용된다.
4. **R1-06**: 꼬리표를 한글 단계 이름으로 바꾼다(문자열 6개).
5. **R1-05**: 히어로 표어를 Pretendard 17px로 줄인다.
6. **R1-11**: `overflow-wrap: break-word` + `text-wrap: pretty/balance`.
7. **R1-09 일부**: `error 0 · warn 0`→"고칠 곳 0 · 살펴볼 곳 0", `— ms` 숨김.
8. **R1-13**: `text-[11px]`→`text-[12px]` 일괄 교체.

그다음은 M 공수인 R1-07(말투 통일), R1-10(질문함 묶음을 위로), R1-02(회색 줄이기) 순서를 권한다.

## 6. 잘 된 점(유지)

- 쪽 머리 패턴(꼬리표 → 28px 제목 → 15px 설명 → 분필 점선)이 6개 쪽에서 같은 순서다.
- 숫자에 `tnum`이 켜져 있고, KPI 값(36px/800)과 라벨(13px/600) 대비가 분명하다.
- `word-break: keep-all`로 어절이 중간에 끊기지 않는다(R1-11의 토큰 분리는 `overflow-wrap:anywhere` 탓).
- 학생 페이지는 h1 27 → 질문 20 → 단계 17 → 버튼 20의 단계가 깔끔하고, 입력칸이 17px이다.
- 인쇄 학생판은 흰 종이, 굵은 제목, 번호 원, 쓰기 칸으로 한눈에 읽힌다(말투만 R1-08).
