# 함께반 v3 디자인 콘셉트 — 칠판과 분필

작성일 2026-11-06. v2는 지난 공모전 앱(masdae-pass, 남색 + teal)의 셸과 색을 그대로 옮겨 함께반만의 얼굴이 없었다(`DESIGN_AUDIT.md`). v3는 화면 구조와 기능은 그대로 두고, 시각 정체성을 사용자가 고른 **"칠판과 분필"**로 바꿨다.

- 값은 한 곳에만 있다: `src/ui/tokens.js` → `tailwind.config.js`(테마 색) → `src/index.css`(`theme()`로 CSS 변수 `--paper`, `--board`, `--chalk`, `--grade-lo/hi/tg` 등).
- masdae-pass 토큰(`brand` teal, slate 남색, violet/sky/emerald/amber/rose)은 `src/`에서 하나도 쓰지 않는다(`grep` 0건).

## 1. 한 줄 콘셉트

> 선생님의 **종이 과정안** 위에, 교실 앞 **칠판**이 한 장 걸려 있다.

- 밝은 화면 = 미색 종이(과정안·학습지). 카드는 조금 더 흰 종이, 따뜻한 1px 선, 옅은 그림자.
- 칠판 = 큰 면 몇 곳에만(한눈에 히어로, 질문함 QR 판, 학생 페이지 머리). 짙은 초록 + 아주 옅은 분필 가루(약 5%) + 나무 받침과 분필 토막 세 개.
- 기억에 남는 한 가지: 히어로의 **"20분"** 밑에 손으로 그은 노란 분필 줄(SVG, 처음 한 번 그려짐).
- 어두운 화면 = 칠판 그 자체. 바탕 `#152B23`, 카드 `#1F3D33`, 글자 분필 흰색.

### 학년색 규칙(텍스트 대비 때문에 단계를 나눔)

학년 기준값(500)은 종이 위 글자로 쓰면 4.5:1이 안 된다(파랑 3.9, 주황 2.8, 연두 3.1). 그래서:

- **채움·막대·빗금·점** = 300–500(분필 톤 그대로).
- **흰 글자를 얹는 단색 블록(■ 직접지도, ★ 통합, 카드 머리)** = 600(`#3A6A9C` 5.6:1, `#A84E28` 5.6:1, `#35705A` 5.8:1).
- **종이 위 학년 글자** = 700(7.2 / 7.0 / 7.1:1). 칠판 위 글자 = 300(5.4 / 5.8 / 6.0:1).
- ■ 직접 = 단색 + 교사 아이콘, □ 간접 = 같은 색 빗금, ★ 함께 = 연두가 두 레인을 가로지름. 세 색은 학년 말고 다른 뜻으로 쓰지 않는다.

### 상태색(뜻 하나에 색 하나)

| 뜻 | 토큰 | 모양 |
|---|---|---|
| 통과 | `ok`(잎 연두, 함께-연두보다 노란 쪽) | 연한 바탕 + 체크·방패 아이콘 |
| 주의 | `warn`(호박) | 연한 바탕 + 삼각 경고 |
| 위반 | `bad`(분필 빨강 `#C8553D`) | 연한 바탕 / 타임라인은 해당 구간에만 점선 테두리 + `R2 20–25` 숫자 꼬리표 |
| 진행 중 | `board` + 분필 노랑 shimmer | 상태 알약 점이 깜빡임 |
| **AI 초안** | `ai`(옅은 라벤더 분필) | **점선 테두리 + ✦(Sparkles) 아이콘** |
| 코드가 판정 | `board` | **실선 테두리 + 자(Ruler) 아이콘** |
| 교사 승인 | `chalk-400` 단색 | 노란 분필 도장 + 방패 체크 |

**AI 표시를 이렇게 고른 이유**: 칠판 위 분필 점선은 "아직 지우고 다시 쓸 수 있는 밑그림"으로 읽힌다. AI가 쓴 것은 늘 밑그림이고, 코드가 판정한 것은 자로 그은 실선, 교사가 승인한 것은 노란 도장이다. 색만이 아니라 **선 모양(점선/실선/단색)**으로도 갈려 색약 사용자에게도 구분된다. 라벤더는 초록·노랑·파랑·주황 어디와도 겹치지 않는 남은 한 색이라 골랐다. 이 세 표시는 히어로의 "AI 초안 → 코드 검사 → 교사 승인" 띠에서 한 번에 소개되고, 파이프라인 단계 카드·묶음 카드·다음 차시 카드(초안은 점선 라벤더 테두리, 승인은 실선 + 노란 링)에서 그대로 반복된다.

### 어두운 화면(칠판)

| 밝은 화면 | 어두운 화면 |
|---|---|
| 바탕 `paper` | `board-950 #152B23` |
| 카드 `paper.card` | `board-900 #1F3D33` |
| 선 `ink-200` | `board-700/800` |
| 본문 `ink-900` | `ink-100 #EFEBE1`(분필 흰색) |
| 보조 글 `ink-500` | `board-300 #A2BFB0`(6.0:1) |
| 주 버튼 칠판 초록 | 분필 노랑 바탕 + 칠판 글자(9.4:1) |

다크 변형은 `@media screen`에서만 켜진다(tailwind `darkMode` variant). 인쇄는 늘 흰 종이에 검은 글자이고, `.chalkboard`·카드 바탕은 인쇄에서 흰색으로 바뀐다.

## 3. 글꼴(모두 로컬 번들, CDN 없음 → 오프라인 데모 가능)

| 역할 | 글꼴 | 라이선스 | 번들 방식 |
|---|---|---|---|
| UI·본문·숫자 | Pretendard Variable | SIL OFL 1.1 | npm `pretendard` 동적 subset(woff2 92조각, 쓰인 글자 조각만 받음) |
| 손글씨 강조 | **Yeon Sung**(연성) | SIL OFL 1.1 | npm `@fontsource/yeon-sung`, woff2만(`src/fonts/yeon-sung.css`) |
| 코드·시각 | JetBrains Mono | SIL OFL 1.1 | npm `@fontsource/jetbrains-mono` latin 400·600 woff2만 |

- **처음엔 Gaegu Bold를 골랐다가 Yeon Sung으로 바꿨다.** 칠판 위 비교(스크래치 `fonttest/`)에서 Gaegu·Gamja Flower·Hi Melody는 자간이 넓어 단어 경계가 흐리고, Nanum Pen Script·East Sea Dokdo는 같은 크기에서 1.5배쯤 작게 보였다. Yeon Sung은 자간이 단단하고 분필 글씨처럼 획 끝이 살아 있어 짧은 제목에 가장 잘 읽혔다. 굵기가 하나라 `font-bold`를 붙이지 않는다(가짜 굵기 방지).
- **손글씨는 한 화면에 1–2곳만**: 한눈에 = "20분" + 한 줄 표어, 다른 쪽 = 쪽 머리 꼬리표(`Design · S1` 등), 학생 = "선생님께"(+ 완료 화면 "보냈어요!"). 숫자·시각·본문·메뉴는 모두 Pretendard.
- 크기(KRDS 참고): `text-xs` 13px / `sm` 15px / `base` 17px, 줄 간격 150% 이상, 화면의 가장 작은 글자 12px(촘촘한 교사 화면의 메타데이터만). 학생 페이지 본문·입력은 16px 이상.

## 4. 화면별 결정

- **사이드바**: 어두운 칠판 사이드바와 비교해 **종이 사이드바(`paper.deep`) + 칠판 초록 활성 알약 + 왼쪽 노란 분필 표시**를 골랐다. 칠판을 사이드바에도 깔면 히어로 칠판이 묻히고 어두운 면이 화면의 1/4을 차지해 흔한 SaaS처럼 보인다. 종이 사이드바는 메뉴 글자 대비가 높고(ink-600 7.0:1), 칠판은 "중요한 순간"에만 나온다.
- **로고**: 작은 칠판 위에 분필 원 두 개(3학년 파랑·4학년 주황)가 겹치고, 겹친 곳이 연두(함께), 아래 노란 분필 한 줄. 파비콘도 같은 그림.
- **셸 배치 버그 수정**:
  1. 상단 오른쪽: AI 알약을 `min-w-0` + 모델명 `truncate`(xl 이상에서만 표시) + 전체 정보는 `title` 툴팁, 버튼은 `shrink-0`, "데모 리셋" 글자는 md 이상. 1024–1920에서 잘림 0(측정: `chipClipped=false`, 가로 스크롤 없음).
  2. 사이드바와 본문 사이 빈틈: v2는 `pl-60` + `mx-auto max-w-[1280px]`라 넓은 화면에서 본문이 남은 칸 가운데로 가며 틈이 생겼다. v3는 `grid-cols-[15rem_1fr]`에 본문·상단 바·꼬리말을 같은 `max-w-[1400px]` 열로 **사이드바에 왼쪽 정렬**(본문 시작 x=240+32px 고정). 1700·1920에서 남는 공간은 오른쪽에만 생긴다.
  3. 사이드바 높이: 그리드 칸이 문서 끝까지 늘어나고 안쪽만 `sticky h-screen`이라, 전체 페이지 캡처에서도 사이드바 배경이 끝까지 이어진다(측정: aside 높이 = 문서 높이).
- **쪽 머리**: 손글씨 꼬리표(노란 분필 짧은 줄 + 장면 이름) → 제목 28px → 설명 → 분필 점선 구분선.
- **타임라인**: 레인 = 학년, 직접/간접 = 채움 밀도(단색/빗금) + 직접 블록의 교사 아이콘, 위반은 해당 구간에만 점선 테두리와 숫자 꼬리표.
- **질문함 묶음**: "✦ N개 묶음" 머리 → 2열 카드(학년·유형·AI 초안 배지 → 고칠 수 있는 주제 + 큰 "N건" → 대표 질문 한 줄 → "포함 기준 · 질문 N건 보기 ›" 펼치기 안에 성취기준·질문 옮기기).
- **다음 차시 카드**: 머리는 학년 단색, 초안 = 라벤더 점선 테두리 + "AI 초안 · 승인 대기", 승인 = 실선 + 노란 링 + 노란 도장, 반려 = 회색.
- **학생 페이지(390px)**: 칠판 머리(로고·점선 상자 안 수업 코드·"선생님께" 분필 밑줄) + 나무 받침, 종이 카드, 학년 버튼은 학년색(선택 시 600 단색), 입력칸은 옅은 공책 줄. 늘 밝은 화면.
- **인쇄(A4)**: 흰 바탕, 검은 글자, 학년색은 레인 머리·막대·학년 번호 상자에만.

## 5. 질감과 움직임

- 칠판 질감: SVG `feTurbulence` 노이즈 160px 타일(불투명 약 5%) + 지운 자국 같은 흰 번짐 3겹(3–7%). 8%를 넘기지 않고 큰 칠판 면에만.
- 분필 밑줄: SVG 경로 2줄 + `feDisplacementMap`(가장자리 거칠게), 0.15초 뒤 0.7초 동안 그려짐. `prefers-reduced-motion`이면 바로 보인다.
- 나머지 움직임은 v2와 같다(rise, ping, shimmer, flow). 카드 호버는 1px 들림 + `shadow-lift`.
