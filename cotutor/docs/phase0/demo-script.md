# 데모 대본

## 90초
| 시간 | 말 | 손 |
|---|---|---|
| 0~20초 | "두 학년을 혼자 맡은 선생님입니다. 3학년 '우리가 사는 곳', 4학년 '지도로 만나는 우리 지역'." | S1에서 3·4학년(같은 학년군 배지), 사회, 단원 2개 → 초안 만들기. FlowRail이 6단계를 지나며 "검사 1건 위반(R10) → 수리 1회 → 통과" |
| 20~35초 | "선생님 동선을 바꿔 보겠습니다." | S2에서 3학년 직접지도 끝 +5분 → 빨간 경고 "3학년 직접지도와 4학년 직접지도가 20~25분 겹칩니다", 승인 비활성 → 되돌리기 → error 0 → 승인 |
| 35~55초 | "심사위원님, QR을 찍어 질문을 보내 주세요." | S3 수업 시작, 큰 QR. 가상 학생 보내기 → 학년별 열에 1초 안에 쌓임, 전화번호는 [전화번호]로 |
| 55~70초 | "AI로 묶으면 교사용 진단 문장이 됩니다." | AI로 묶기 → 묶음 카드(라벨·포함 기준·연결 성취기준·대표 질문) |
| 70~85초 | "다음 시간, 제가 다른 학년에 가 있는 10분 동안 할 카드입니다." | S4 카드 만들기 → 제목 한 단어 고치고 승인 → 다음 차시 미리보기 검사 통과 |
| 85~90초 | "학생판에는 교사 메모가 없습니다." | 3학년 학생판 인쇄 미리보기 |

## 3분 확장판
90초 흐름 + (1) S2에서 블록을 간접지도로 바꿔 R4 → 카드 만들기, (2) 학생 페이지를 화면에 띄워 이름 입력칸이 없음을 보여 줌, (3) 데이터 원칙 링크, (4) "같은 요청, 두 결과": 범용 챗봇 수업안의 코드 환각·겹치는 시간표 vs 검사기 통과본.

## 장애 시 대본
- 모델이 느리거나 끊기면: "지금은 녹화해 둔 응답으로 보여 드리겠습니다." → 서버를 `AI_MODE=replay`로 재시작(또는 live 실패 시 자동으로 녹화 응답 사용, 화면 구석에 `replay·ollama 녹화` 표시).
- QR이 안 열리면: 주소를 직접 입력(화면의 URL), 그래도 안 되면 "가상 학생 보내기".
- 화면이 꼬이면: 우측 위 "데모 리셋"(10초 안에 초기 상태).
