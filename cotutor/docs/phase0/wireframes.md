# 화면 와이어프레임과 수용 기준

실제 화면은 `screenshots/`(e2e가 매번 다시 찍음)를 기준으로 한다.

```
S1 /            [수업 조건: 학년·교과·단원·시간·협력강사 | 배지: 같은 학년군]   [과정안 ■□★ 표 | 성취기준 칩 | AI 초안/교사 승인]
                [진행: FlowRail 맥락→계획→골격→채움→검사→수리 + 단계별 한 줄]   [◎○△ 평가 | 검사·수리 기록 | AI 경로]
S2 /timeline    [3학년 레인 ■■■■□□□□ ★] [4학년 레인 □□□□■■■■ ★]           [R1~R12 패널, 교사 이동, 직접지도 분]
                [블록 상세: 모드 전환, 시작/끝 ±5분, 카드 만들기]             [승인(error 0일 때만)]
S3 /live        [QR + 코드 + URL(+localhost 경고)] [지금 질문] [가상 학생]     [3학년 열 | 4학년 열 → AI로 묶기 → 묶음 카드]
S4 /next        [3학년: 보충·심화 카드 편집/승인/반려] [4학년: …]             [다음 차시 미리보기(검사 통과)] [학생판·교사판 인쇄]
학생 /s/?c=     [선생님 질문] [3학년|4학년] [글 200자] [보내기] → [보냈어요! / 하나 더 보내기]
```

수용 기준은 명세 §3-1을 그대로 쓰고, 자동 확인 결과는 `npm run e2e` 출력(35개 항목)에 있다.
